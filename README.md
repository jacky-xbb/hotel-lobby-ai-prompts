# Hotel Lobby AI Prompts

A tiny Go CLI that writes a storyboard prompt for a two-photo music video. It is useful when you want a consistent starting prompt before generating a playful duet or short social clip.

## Run

```bash
go run . -subjects "a chef and a cat" -mood jazzy
```

The output is plain text, so you can edit it before using it in a video generator. You can try the current photo-to-music-video workflow at [Hotel Lobby AI](https://hotellobbyai.net/).
